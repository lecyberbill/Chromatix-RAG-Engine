# 🛠️ Procédure d'Installation Simplifiée

Suivez ces 3 étapes pour installer Scientific RAG sur votre machine Windows.

## Pré-requis
1.  **Ollama :** Téléchargez et installez-le sur [ollama.com](https://ollama.com).
2.  **Node.js :** Téléchargez et installez la version LTS sur [nodejs.org](https://nodejs.org).
3.  **Python 3.10+ :** Téléchargez-le sur [python.org](https://python.org).

---

## Étape 1 : Téléchargement du modèle
Ouvrez un terminal (CMD ou PowerShell) et tapez :
```bash
ollama pull llama3
```

## Étape 2 : Installation automatique
Double-cliquez sur le fichier **`setup.bat`** à la racine du projet.
*   Cela va créer l'environnement virtuel.
*   Cela va installer toutes les bibliothèques nécessaires (Backend et Frontend).

## Étape 3 : Démarrage
Double-cliquez sur **`start.bat`**.
*   Votre navigateur s'ouvrira automatiquement sur l'interface.
*   Vous pouvez commencer à importer vos documents !

---

> [!NOTE]
> **Futur :** Une version **Docker** est prévue pour simplifier encore davantage le déploiement en encapsulant tous les services dans un conteneur unique.
